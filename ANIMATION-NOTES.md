# Animated GitHub Profile v2

This version uses animated GIF sections in the profile README instead of relying on animated SVG playback.

Why GIF:
GitHub's current documentation says SVGs rendered on GitHub do not support inline scripting or animation. GIF is therefore used for visible motion in the README.

- hero.gif
- about-life.gif
- stack.gif
